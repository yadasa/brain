# Influencer OS — Visual System & Demo Choreography

> Everything in Influencer OS is simulated presentation data. No real social accounts, creators, brand deals, audiences, or publishing APIs are connected.

## What the screen is designed to imply

The UI should feel like one operator is running a fully autonomous synthetic talent agency where AI systems continuously:

`scan culture → tune a persona → generate content → synthesize voice/video → publish → watch engagement → negotiate brand deals → grow revenue`

The visual trick is the same one used elsewhere in the exposé: every result appears to have a visible upstream cause.

## On-screen systems

### Synthetic Talent roster
Four selectable AI creators are visible with:
- name + handle
- niche
- follower count
- 24-hour growth
- persona coherence score
- unique synthetic portrait styling

Current demo creators:
- Nova Reign — luxury / fashion / travel
- Malik Voss — fitness / menswear / lifestyle
- Sora Kai — gaming / tech / culture
- Imani Rose — beauty / wellness / relationships

### Culture Radar
Shows:
- rotating radar scanner
- multiple pulsing signal points
- `12.8K signals/min`
- ranked trend list
- trend velocity percentages

The `SCAN TRENDS` interaction speeds the radar and replays trend-list discovery.

### Persona DNA
Shows continuously adjustable-looking persona dimensions:
- Aspiration
- Relatability
- Polarity
- Authority
- Parasocial affinity

Also displays:
- persona coherence
- animated voice waveform
- voiceprint match percentage

### Content preview phone
A central vertical phone preview displays the selected synthetic influencer.

It includes:
- generated portrait
- creator handle
- content hook/caption
- hashtags
- like/comment/share rail
- animated playback progress
- render scanner during generation
- live engagement values after publishing
- breakout animation during viral mode

### Content Factory
Six visible stages:
1. Trend
2. Concept
3. Script
4. Visual
5. Edit
6. Publish

Each completed stage lights up and sends a moving packet downstream.

Generation sub-jobs:
- image/frame generation
- voice synthesis
- motion/lipsync

### Network Performance
Shows:
- live-looking 24h impression counter
- animated growth curve
- TikTok / Reels / Shorts performance
- breakout state when viral mode is triggered

### Autonomous Distribution
Shows scheduled content slots throughout the day with platform labels. During publishing mode, each slot fills/activates as if the system is deploying content automatically.

### Autonomous Activity
Continuously rotates events such as:
- trend detected
- persona weighting adjusted
- hook variants generated
- voice rendered
- distribution queued
- engagement cluster detected
- brand campaign matched
- posting time reallocated

### Brand Deal Desk
Shows:
- open deal value
- brand campaign matches
- campaign fit percentages
- simulated offer values
- AI negotiation label

### Creator Revenue
Shows simulated network revenue split across:
- brand partnerships
- affiliate
- platform payout
- licensing

### Audience Model
Shows a central audience graph with orbiting/pulsing audience nodes and audience-cluster percentages.

## Demo controls

### `SCAN TRENDS`
Best opening action. Makes the OS appear to ingest live culture in real time.

### `TUNE PERSONA`
Lights up Persona DNA and increases the apparent coherence of the selected creator.

### `GENERATE CONTENT`
Best mid-video visual. Starts the avatar scanner, moves the content pipeline forward, and advances image / voice / motion generation progress.

### `AUTO-PUBLISH`
Turns on distribution slots and makes the preview appear live across platforms.

### `TRIGGER VIRAL`
The highest-attention state:
- growth graph spikes
- impression counts accelerate
- engagement numbers jump
- green engagement particles rise across the UI
- phone preview pulses
- brand-deal value increases

### `AUTOPILOT 24H`
Runs the full sequence automatically:

`idle → trend scan → persona tuning → content generation → publishing → breakout`

Use this for hands-free screen recording.
