# LARP // Autonomous Revenue OS

A deliberately theatrical, visuals-first 3D "AI agent command center" for the guru-exposé video series.

Everything in this build is **simulated presentation**. Revenue, pipeline, agent activity, task throughput, decision counts, confidence, latency, trace IDs, close events, and system telemetry are mock visual effects. There is no agent architecture or business automation behind this scene.

## Run locally

```bash
cd larp
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

## Current visual system

- React + Vite shell
- React Three Fiber / Three.js scene
- Central emissive/distorted AI core
- 8 primary business-agent nodes
- 12 secondary routing/signal nodes
- 44-node ambient signal swarm
- Curved inter-agent routes instead of flat straight connectors
- Multiple moving packets per high-priority route
- Periodic agent execution bursts
- Expanding core "decision" waves
- Orbiting core and agent satellites
- Rotating scanner field and faint wireframe data shell
- Autonomous cinematic camera drift/orbit
- Bloom, vignette, subtle noise, fog, stars, particles
- Perspective HUD grid, reticles, scan sweep, edge telemetry
- Simulated revenue and pipeline counters
- Continuously changing decision count
- Live agent activity feed
- Periodic autonomous-close / recovered-revenue / pipeline-created events
- Four-stage fake execution trace with animated packets
- Capital-efficiency radial gauge and allocation bars
- Fake model confidence, inference latency, queue velocity and health states
- Responsive reductions for smaller screens

## Why the second pass feels more "alive"

The first pass mainly showed **activity**. The enhanced pass adds **apparent causality**: signals travel through the graph, agents visibly fire, a decision trace advances, and then a revenue-style outcome appears. That sequence encourages the viewer to infer that the animation is evidence of a real autonomous system even though all of it is decorative.

Other credibility cues are intentionally layered in: changing-but-specific values, trace IDs, sub-100ms timings, healthy/nominal language, selective legibility, rotating system geometry, intermittent rather than uniform motion, and finance-coded green only when an apparent outcome occurs.
