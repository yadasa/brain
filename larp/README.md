# LARP // Autonomous Revenue OS

A deliberately theatrical, visuals-first 3D "AI agent command center" for the guru-exposé video series.

This first pass is **100% simulated presentation**. The revenue, pipeline, agent activity, task throughput, decision counts, and status telemetry are deterministic/mock UI effects. There is no agent architecture or business automation behind this scene yet.

## Run locally

```bash
cd larp
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

For a production build:

```bash
npm run build
npm run preview
```

## Current visual system

- React + Vite shell
- React Three Fiber / Three.js scene
- Central emissive/distorted AI core
- 8 primary business-agent nodes
- 12 secondary signal nodes
- Animated major + cross-agent connections
- Multi-speed data packets traveling across edges
- Slow node drift and camera parallax
- Bloom, vignette, subtle noise, fog, stars, particles
- Glass HUD overlays
- Simulated revenue and pipeline counters
- Live agent activity feed
- Capital-efficiency radial gauge
- System throughput/status rail
- Responsive reductions for smaller screens

## Art direction

The scene intentionally uses the visual language common to "autonomous AI company" social content: selective legibility, finance-coded green, intelligence-coded cyan, dense graph topology, constant micro-motion, specific-looking metrics, system-health language, and expensive-looking glass/bloom treatment.
