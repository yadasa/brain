# 2026-04-12 — Pure AI mode (proxy) + website /download auth

## Pure AI mode: why it never activated
### Symptom
- Pure AI mode enabled, but no console logs:
  - `exempliphai: Pure AI mapping batch …`
  - `exempliphai: Hybrid mapping candidates …`

### Root cause
- The Gemini provider is **proxy-only** (routes via `chrome.runtime.sendMessage({ action: 'AI_PROXY', ... })`).
- Content script incorrectly gated both Pure AI + Hybrid AI behind `res['API Key']`.
  - If missing, Phase 2 returned silently, so no Pure AI logs ever appeared.

### Fixes shipped
- `d9b2ec3`: remove API-key gates for:
  - Pure AI mapping
  - Hybrid AI mapping
  - AI dropdown option fallbacks
  so everything uses the proxy as intended.
- `4e3410e` (compat): merge `API Key` from local storage for older installs. Not required after `d9b2ec3`.

## Website changes

### Fix shipped
