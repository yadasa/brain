# 2026-04-12 — The Garden single-site build status

## Goal
Ship a functioning, mobile-first, single-site giving/admin/kiosk platform on Firebase + Stripe, where production setup is mostly “add live secrets + seed data + set role claims”.

## What was implemented
- Firebase Functions
  - Stripe PaymentIntent creation (callable)
  - Stripe webhook reconciliation (raw-body signature verify)
  - Donations ledger writes in Firestore
- Firestore
  - Rules + indexes in-repo
  - Seed JSON for initial funds
- Web (single site)
  - Routes:
    - `/` home
    - `/give` giving (Stripe Elements)
    - `/profile` sign-in + role display
    - `/admin` admin ledger (role-gated)
    - `/kiosk` kiosk giving UI
  - Hosting serves `apps/web/dist` (single site)
